# Local font provenance

The site bundles every design-critical typeface so its poster identity does not depend on a visitor's installed fonts or a runtime font service.

- **Balsamiq Sans** (`assets/fonts/balsamiq-sans/`) is the body and Comic Sans-style reading face. Regular and Bold TTFs come from the [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/balsamiqsans).
- **Modak** (`assets/fonts/modak/`) is the existing display face. The TTF comes from the [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/modak).
- **Caveat** (`assets/fonts/caveat/`) is Kevin's signature face. The variable TTF comes from the [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/caveat).
- **Pacifico** (`assets/fonts/pacifico/`) is Ryan's signature face. The TTF comes from the [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/pacifico).
- **Sacramento** (`assets/fonts/sacramento/`) is Sam's signature face. The TTF comes from the [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/sacramento).

Each family is distributed under the SIL Open Font License 1.1. Its upstream `OFL.txt` is preserved beside the corresponding font binaries. The older bundled Spicy Rice asset retains its existing license file in `assets/fonts/OFL.txt`, although it is not part of the current page typography.
